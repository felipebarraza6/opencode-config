# implement-change

Implementa un cambio aprobado siguiendo el plan.

## Cuándo usar

- Cuando existe un plan aprobado.
- Para tareas acotadas de código.

## Pasos

1. Revisa el plan y confirma el alcance.
2. Lee los archivos que vas a modificar.
3. Aplica los cambios de forma mínima y reversible.
4. Reutiliza patrones existentes.
5. Agrega o actualiza tests según la estrategia definida.
6. Ejecuta validaciones locales.
7. Documenta decisiones y limitaciones.

## Salida esperada

- Resumen de la solución.
- Lista de archivos modificados.
- Tests agregados o actualizados.
- Comandos ejecutados y sus resultados.
- Decisiones tomadas.
- Pendientes o limitaciones.

## Restricciones

- No salgas del alcance acordado.
- No inventes APIs o dependencias.
- No modifiques secretos, infraestructura o producción.
- Pide aprobación antes de comandos destructivos.
